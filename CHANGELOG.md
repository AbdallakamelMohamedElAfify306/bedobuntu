# Changelog

## 0.1.0 — 2026-10-31

- Initial public source drop of Cheetah Dual.
- Ubuntu 24.04 (noble) + Phosh build pipeline adapted from Omarchy Mobile.
- Slot-B flash/reflash helpers with a hard partition allowlist.
- Shared ext4 partition tooling (create / mount on Ubuntu and Android).
- Two-way switch: Android app (Switch to Ubuntu) + Phosh "Reboot to Android" GUI.
- Ubuntu health / lock-screen / hardening kit.
- Android Magisk helper scripts (root-hide, root-toggle, Shamiko install helpers,
  backup kit) without third-party module binaries.
- Secrets, device identifiers, private keys, and boot images removed for publication.
