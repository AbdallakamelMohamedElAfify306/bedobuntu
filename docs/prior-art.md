# Prior art and differences

| Project | What it is | Difference |
|---------|------------|------------|
| Omarchy Mobile | Arch + Hyprland on Pixel including cheetah | Not Ubuntu, not Phosh |
| Ubuntu Touch / UBports | Phone Ubuntu ports | No official cheetah port |
| postmarketOS | Mainline phone Linux | No official cheetah port at time of writing |
| Slot-switch apps (e.g. Nothing Phone community) | Toggle A/B | Different device; we add Ubuntu+Phosh+shared |

Claim used in README: first **public Ubuntu + Phosh** port for cheetah with this
dual-boot and switch design. Do not claim "first dual-boot" or "invented a new OS".
